# Marvis · 投资地图

一个**给普通人的投资决策流程工具**：先决定「多少钱可以进股市」，再决定「怎么放、放多少、什么时候调」。

它不荐股、不给目标价、不预测收益。默认首页是「投资地图」，11 个专业面板被收进二级菜单。

---

## 它怎么带你走

1. **认识自己** — 填可投资资产、月收入支出、应急金、高息负债、投资期限，做 5 题风险测评。
2. **安排钱** — 按「应急金 → 高息负债 → 3 年内要用的钱 → 长期不用的钱」四桶分配。前置条件不满足时，权益比例直接锁为 0。
3. **看市场位置** — 用真实宏观序列的历史分位判断风险环境（此项依赖外部数据，不可用时明确显示"不可用"）。
4. **定执行规则** — 仓位计算器、下单前 6 问、再平衡检查、复盘日志。
5. **记录与复盘** — 手动记账持仓，回看决策质量而不是只看盈亏。

配置比例由三条约束取小得出：**投资期限上限、风险问卷得分、你能接受的最大浮亏**。市场状态只做「恶化时下调」的单向调整，不会因为"行情好"而加仓。

## 它不是什么

- 不是荐股软件，不提供具体买卖指令、目标价、评级或收益承诺。
- 不是行情终端。行情来自公开接口，可能延迟、缺失或被上游限流。
- 不是自动交易或券商对接工具。持仓为手动记账，不会同步真实账户。
- 不具备证券投资咨询资质。所有输出都是通用框架，不构成投资建议。

## 快速开始

```bash
npm install
npm run dev          # 开发模式，默认 http://localhost:5173
```

生产模式（单端口同时托管静态文件与数据转发）：

```bash
npm run build
npm run serve        # 默认 http://127.0.0.1:8080
```

> `npm run serve` 只监听回环地址，局域网其它设备访问不到。

### Windows 一键启动（不用敲命令）

打开项目里的 `一键启动` 文件夹：

| 双击文件 | 作用 |
|---|---|
| `Marvis 桌面版.lnk` | 单文件程序，自动启动本地服务并打开浏览器；页面右下角「退出程序」可关闭 |
| `启动软件.bat` | 用源码方式构建并启动正式版（`http://127.0.0.1:8080`），关闭黑色窗口即停止 |
| `启动开发模式.bat` | 开发模式热更新（`http://localhost:5173`），改代码后自动刷新 |

首次运行 `.bat` 会自动安装依赖并构建。`Marvis.exe` 已生成在项目根目录；如需重新打包，运行 `desktop/build-exe.bat`。

### 数据源的前置条件（重要）

Yahoo、CBOE、ConvexTrade 对中国大陆直连通常返回 403 / 超时；Node/Vite 不会自动使用 Windows 系统代理，因此程序会在启动时自动探测本机出海代理：

1. `MARVIS_PROXY`（手动指定，优先级最高）；
2. `HTTPS_PROXY` / `ALL_PROXY`；
3. `127.0.0.1` 的 `7897` / `7890` / `10809` / `1080`；
4. 都没有则直连，并在页面数据健康条中提示。

走代理的源：Yahoo、CBOE、ConvexTrade。  
保持直连的源：FRED、东方财富、腾讯、新浪（实测经海外代理反而失败）。

```powershell
# 手动指定（可选；不设置也能自动探测 7897）
$env:MARVIS_PROXY='http://127.0.0.1:7897'
npm run dev
```

**降级链（不会用模拟值顶替真实值）：**

- Yahoo 不可达 → 恒生/上证用腾讯现货指数兜底（来源点变橙色并标注“腾讯现货兜底”）；期指/汇率/商品显示「缺」；
- 东方财富被网络重置 → A 股板块自动切换腾讯行业榜（31 个行业，含 5/20/60 日涨跌与主力净流入），再退新浪板块（仅当日价格）；
- FRED 失败 → 先走 ConvexTrade 镜像；仍失败时，利率腿（2Y/3M/5Y/10Y/30Y）用美国财政部官方曲线补齐，其余指标显示「缺」。

**诊断：**

```bash
npm run probe
```

输出本机代理、Yahoo 直连/代理、FRED、CBOE、Convex、东财、腾讯、新浪的可用性，并给出处理建议。应用内 `/proxy-status` 返回实际使用的代理；首页数据健康条展开也能看到。

> 腾讯 `zljlr` 单位为万元，程序已换算为亿元；`zdf_d5/d20/d60` 是 5/20/60 日涨跌幅，不是年化。

## 数据可信度分级

页面上的每个数字应能对应以下之一（组件 `SourceBadge`）：

| 标记 | 含义 | 能否用于决策 |
|---|---|---|
| 真实接口 | 来自公开上游的历史/实时序列 | 可参考，注意延迟 |
| 模型估算 | 前端按规则推算，非上游原始值 | 仅作方向参考 |
| 演示常量 | 写死的示例数据 | **不能** |
| 数据不可用 | 上游未返回，引擎拒绝编造 | 不能 |

当前明确标注为演示数据的页面：**板块轮动**（全部）、**智能组合推荐**（资产比例示例）。
技术分析已改为读取真实日线，取不到数据时直接提示，不再生成模拟 K 线。

## 已知限制

- 「告警」页只保存规则，当前版本**不会自动轮询触发**，需要人工查看。
- 持仓页为手动记账，现价需自己更新，不会自动同步券商。
- 桌面壳 `Marvis.exe` 是把前端资源注入 Node 运行时的自解包程序，未做代码签名，Windows SmartScreen 可能提示"未知发布者"。
- 用户数据（画像、持仓、复盘）只存在本机浏览器，清除浏览器数据会丢失，暂无导出功能。
- `docs/` 下的优化方案与实施报告属于历史规划，部分指标（如"数据 100% 真实""Phase 1 完成"）与当前实现不符，以本 README 为准。

## 合规

- 本工具不构成投资建议，不承诺任何收益。
- 不具备证券投资咨询业务资格。
- 历史数据与历史回撤不代表未来表现。
- 投资有风险，本金可能亏损。
