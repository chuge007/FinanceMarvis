# 代理与数据源配置（Clash / Mihomo）

> 目标：让 Yahoo、CBOE、Convex、FRED 走一个稳定的海外节点，同时让东财、腾讯、新浪保持直连。
> 本文只写通用步骤，**不要把订阅链接、节点密码写进仓库或截图**。订阅链接是凭证，泄露后应在机场后台重置。

## 1. 把订阅导入 Clash 客户端

任选一个客户端：

| 客户端 | 适用 | 默认混合端口 |
|---|---|---|
| Clash Verge Rev | Windows/macOS，推荐 | 7897 |
| Clash for Windows | Windows（旧但稳定） | 7890 |
| Mihomo Party | Windows/macOS | 7897 或自定义 |
| v2rayN | Windows | 10809 |

以 Clash Verge Rev 为例：

1. 打开「订阅 / Profiles」→「新建」→ 选择「远程」。
2. 把机场给的 **Clash 订阅链接**粘贴进去，名称随意（例如 `marvis`），保存。
3. 点「更新」拉取节点列表。
4. 在「代理 / Proxies」里选一个 **美国 / 日本 / 香港** 节点；优先选延迟低、丢包少的。
5. 打开「系统代理 / System Proxy」；如果客户端支持 **TUN 模式**，也可以开 TUN（Node 程序在 TUN 下也能被接管）。
6. 确认「混合端口 / Mixed Port」是多少（Clash Verge 常见 7897）。

> 如果机场订阅里同时有「直连 / DIRECT」和「全球 / GLOBAL」，不要用 GLOBAL 模式跑本应用：东财、腾讯、新浪会被绕到海外，反而变慢或失败。用「规则 / RULE」模式，或至少让 CN 域名直连。

## 2. 让 Marvis 使用这个端口

程序会按以下顺序自动探测，不需要改代码：

1. `MARVIS_PROXY` 环境变量；
2. `HTTPS_PROXY` / `ALL_PROXY`；
3. `127.0.0.1` 的 `7897` / `7890` / `10809` / `1080`；
4. 都没有则直连。

### 开发模式

```powershell
# 如果客户端端口不是 7897，手动指定
$env:MARVIS_PROXY='http://127.0.0.1:7897'
npm run dev
```

### 双击 exe

exe 会自动探测上述端口。若端口不在列表里，创建一个 `启动Marvis.bat`：

```bat
@echo off
set MARVIS_PROXY=http://127.0.0.1:7897
start "" "D:\FinanceMarvis\Marvis.exe"
```

### 验证

```bash
npm run probe
```

输出应类似：

```text
代理: http://127.0.0.1:7897（自动探测）
 OK  Yahoo 经代理   200
 OK  Yahoo spark    200
 OK  财政部曲线     200
 OK  CBOE 经代理    200
FAIL 东财 直连      socket hang up
 OK  腾讯行业榜     200
```

应用内还可以看：

- `/proxy-status`：返回实际使用的代理；
- 首页顶部数据健康条 →「查看原因」→「出海通道」。

## 3. 哪些源走代理，哪些直连

| 源 | 通道 | 原因 |
|---|---|---|
| Yahoo Chart / Spark | 代理 | 直连 403，代理 200 |
| CBOE 每日统计 | 代理 | 页面无 CORS，且大陆直连常失败 |
| ConvexTrade | 代理 | 按地区封锁；当前接口 404 时会自动回退 |
| FRED | 直连 → 代理重试 | 部分节点能连 FRED；两条都失败才熔断 |
| 美国财政部 | 直连 | 官方 CSV，直连稳定 |
| 东方财富 | 直连 | CN 站点；海外节点反而会重置 |
| 腾讯 / 新浪 | 直连 | CN 站点；走代理会变慢或失败 |

## 4. 为什么「换了好节点还是慢」

程序的耗时通常不是单次请求，而是**等待失败的超时**：

- FRED 直连 2.5s + 代理 3s；连续两条失败后熔断 5 分钟；
- Yahoo 单只 8s；批量 spark 18 只/批；
- 套接字代理只对本机端口做 TCP 探测，不做外网测速。

提速建议：

1. 在 Clash 里选一个 **到 Yahoo / FRED 延迟低** 的节点（不只看 Speedtest）。
2. 用「规则」模式，让 CN 域名直连，别把所有流量都绕出去。
3. 首次打开会拉一次全量，之后有 5 分钟内存缓存和 localStorage 冷启动缓存；第二次打开会快很多。
4. 如果 FRED 长期 404/超时，利率会由财政部曲线兜底；HY OAS、NFCI、WALCL 等 FRED 独有序列会显示「缺」，这是数据边界，不会用模拟值补。
5. 订阅节点很多时，Clash 的「自动选择 / 延迟测速」可能选到不适合 FRED 的节点；可以手动固定一个美国节点再测 `npm run probe`。

## 5. 安全提醒

- 订阅链接等同于账号密码，**不要提交到 Git、不要发群、不要放在截图里**。
- 如果链接已经公开，去机场后台「重置订阅」生成新链接。
- 本项目不会把订阅链接写入代码；代理只从环境变量或本机端口探测读取。
