# GitHub 全量数据源接入方案（2026-11-27）

> 目标：把 `D:\FinanceMarvis\Github` 下已落盘的 46 个开源项目，以及上文提及但无 GitHub 仓库的数据源（EODHD、IMF、OECD、BLS 等），统一接入 Marvis。
>

## 0. 接入总原则（继承既有规则，不推翻）

1. **四层分工**：源码资产层（`Github\`，只读不打包）→ 能力清单层（`scripts/gen-project-capabilities.mjs` 生成 JSON）→ 数据服务层（Node 适配器直连 + Python 侧车）→ 产品视图层（全景/策略/研究页）。
2. **每条数据唯一主源**：稳定性 S1 > S2 > S3 > S4 > S5 > S6 → 当前可达性 → 覆盖广度 → 接入成本。级差 ≥2 强制换主。
3. **不混源、不插值、不模拟**：缺数据显示「缺」并点名缺哪条线；备源标注 caliber，不与主源拼装。
4. **Key 源按需启用**：没 Key 就从注册表摘除，界面显示「需 Key」；429/402 立即降级不重试烧配额。
5. **Python 不进 exe**：所有 Python 库只在本地侧车 `sidecar/data_main.py` 内调用，产物是 JSON，经 `127.0.0.1` 回环交给 Node。
6. **合规分级**：官方源（S1）优先；爬虫封装（S4）只做特色品类与备源；商用数据需用户自备 Key/授权。

## 2. 四层接入模型与改动点

```
Github\ 源码（只读，不进 bundle/SEA）
   │  扫描公开 API
   ▼
scripts/gen-project-capabilities.mjs ──► src/core/data/projectCapabilities.generated.ts
   │                                  └─► public/data/project-capabilities.json
   ▼
数据服务层
   ├─ Node 直连：server/adapters/*.mjs（免费 HTTP 源优先）
   └─ Python 侧车：sidecar/data_main.py（需 Python 库的源）
          ▲ server/local/dataSidecar.mjs 管理进程 + ALLOWED 白名单
   ▼
server/adapters/index.mjs 汇总 SERIES / SNAPSHOTS → API → 全景/策略/研究页
```

### 2.1 新增仓库登记（必做，零运行风险）

在 `scripts/gen-project-capabilities.mjs` 的 `PROJECTS` 数组追加 17 项。格式沿用现有对象，示例：

```js
{ id: 'global-stock-data', label: 'Global Stock Data', dir: 'global-stock-data',
  repo: 'simonlin1212/global-stock-data', group: '全球市场',
  stability: 'S1', status: 'catalog-only', requires: [],
  markets: ['us','global'], primaryFor: [], fallbackFor: [], license: 'Apache-2.0' },
{ id: 'wbgapi', label: 'wbgapi', dir: 'wbgapi', repo: 'tgherzog/wbgapi',
  group: '宏观/另类', stability: 'S1', status: 'python-required',
  requires: ['python311'], markets: ['global'], primaryFor: [], fallbackFor: [], license: 'MIT' },
{ id: 'pysdmx', label: 'pysdmx', dir: 'pysdmx', repo: 'bis-med-it/pysdmx',
  group: '宏观/另类', stability: 'S1', status: 'python-required',
  requires: ['python311'], markets: ['global'], primaryFor: [], fallbackFor: [], license: 'EPL-2.0' },
```

其余新增项按同一模板登记：`FinceptTerminal`、`gloomberb`、`akhub`、`awesome-quant`、`awesome-financial-data-apis`、`a-stock-data`、`polygon-api-client`、`finnhub-python`、`tiingo-python`、`simfin`、`questdb`、`FinanceToolkit`、`pytrends`、`FinNews`、`realtime-newsapi`、`automated-market-report`、`stock-market-scraper`。

生成：`node scripts/gen-project-capabilities.mjs`，产物写入 `src/core/data/projectCapabilities.generated.ts` 与 `public/data/project-capabilities.json`。

> 注意：`public/data/project-capabilities.json` 已超 512KB，GitNexus 索引会跳过，属正常现象。

### 2.2 Node 直连接入（免 Key 优先）

适用：`global-stock-data` 中的官方源端点、BLS、IMF/ECB/OECD SDMX、World Bank。

- 新建 `server/adapters/globalOfficial.mjs`，用 `defineSeries` 定义序列，走 `ctx.transport.getJson`。
- 在 `server/adapters/index.mjs` 的 `baseSeries` / `snapshots` 中展开导入。
- TTL 按 `FREQ_TTL`（daily 900s、monthly 43200s），不另行硬编码。
- 参考 `server/adapters/macroGlobal.mjs` 的 `wb:*` / `nyfed:SOFR` 写法。

### 2.3 Python 侧车接入（需库源）

改动文件与顺序：

1. `sidecar/requirements-data.txt` 追加：`wbgapi>=1.0.12`、`pysdmx`、`eodhd`（如启用）。
2. `sidecar/data_main.py`：
   - `LIB_NAMES` / `ALLOWED_LIBS` 追加 `'wbgapi'`、`'pysdmx'`。
   - 新增白名单方法 `wbgapi.series`（参数：indicator/country/date range）、`sdmx.dataset`（参数：provider=IMF|ECB|BIS|OECD、dataset key）。
   - 复用 `ok()` / `fail()` / `rows_of()`，缺库走 `missing_lib()`，异常走 `UPSTREAM_ERROR`。
3. `server/local/dataSidecar.mjs` 的 `ALLOWED` Set 追加上述方法名。
4. `server/adapters/dataSidecar.mjs` 增加 `defineSeries` / SNAPSHOT 条目，`fetch` 调 `ctx.dataSidecar.call(...)`。
5. `server/api/health.mjs` 与 `server/adapters/index.mjs` 的 `capabilities` 数组增加可用性探测项。

> `global-stock-data` 本身是 Markdown + 内嵌 Python 的 Skill 文件，不直接 import；按其 README 的端点用纯 `requests` 复刻到侧车，避免引入 18 个上游源的依赖负担。

## 5. 不在本次接入范围（明确边界）

- **交易执行**：FinceptTerminal / vnpy / freqtrade / ccxt 的下单能力只登记不接入，程序默认 `allowRealTrading=false`。
- **完整逐笔数据仓库**：QuestDB 只作本地时序库候选，不内置落库管线。
- **商业数据再分发**：所有 S2 Key 源仅用户本机使用，不缓存转售、不打包进 exe。
- **OpenBB / FinceptTerminal 二进制**：只参考其连接器目录，不把 AGPL 代码链进主程序。
