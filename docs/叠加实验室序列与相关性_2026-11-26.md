# 叠加实验室：序列结构与相关性口径（2026-11-26）

> 目的：把「纳指÷标普」「半导体÷纳指」「实际利率拆分」「金融条件传导」「流动性管道」做成可复用、可追溯的序列，而不是每次临时拼图。

## 1. 数据结构

| 文件 | 作用 |
|---|---|
| `src/core/data/overlayCatalog.ts` | 序列目录：id、名称、来源、依赖、颜色、频率、说明；预置组合与相关配对 |
| `src/core/data/overlaySeries.ts` | 原始取数 + 派生计算 + 滚动 Z；按需加载、5 分钟缓存 |
| `src/stores/useOverlaySeriesStore.ts` | React 单例：只加载当前选中/相关配对需要的序列 |
| `src/modules/v4/components/OverlayLab.tsx` | 叠加页：预置、选线、统一 Z 轴、相关性面板 |
| `src/modules/v4/components/OverlayCorrTable.tsx` | 多配对滚动相关表；纳指/标普敏感度差 |
| `src/core/charts/OverlayChart.tsx` | Chart.js 单轴叠加图；修复空数据时 canvas 未挂载导致曲线空白 |

**原则**：宏观/指数线统一滚动 Z（250 日）；相关系数单独 −1~1 面板，不混轴；派生只用日期交集，不插值。

## 2. 原始序列

### FRED（直连失败自动走 `/fred-proxy`）

- 利率：`DFII10`、`T10YIE`、`DGS10`、`T10Y2Y`
- 信用/波动：`BAMLH0A0HYM2`、`VIXCLS`
- 金融条件：`NFCI`
- 流动性管道：`WALCL`（周）、`RRPONTSYD`（日）、`WRESBAL`（周）、`WTREGEN`（周）

> 利率腿优先用美国财政部官方曲线（2Y/3M/5Y/10Y/30Y、DFII10、T10YIE），FRED 只做兜底；因此 FRED 断线时，利率与盈亏平衡通胀仍可用。

### Yahoo

- `SPY`、`QQQ`、`SMH`（半导体 ETF，SOX 的可交易代理）、`IWM`
- `DX-Y.NYB`（ICE 美元指数，广义美元不可达时的旁证）
- `^VIX`（VIX 的 Yahoo 同口径代码）

## 3. 派生序列

| id | 公式 | 解读 |
|---|---|---|
| `QQQ_SPY` | `ln(QQQ / SPY)` | 久期/成长风格因子；走强=折现率行情，走弱=增长/盈利重新定价 |
| `SMH_QQQ` | `ln(SMH / QQQ)` | AI 资本开支因子；走阔=分子驱动（订单/capex），走平=分母驱动 |
| `NET_LIQ` | `WALCL/1000 − RRPONTSYD − WTREGEN` | 净流动性，单位十亿美元；WALCL 百万→十亿 |
| `QQQ_DFII10_CORR` | 60 期滚动相关（QQQ 对数收益 vs DFII10 一阶差分） | 强负是折现率行情；转正=市场在交易增长/AI capex |
| `SPY_DFII10_CORR` | 同上，标普 | 与 QQQ 那条并排看差值；差值收窄=久期溢价消失 |
| `QQQ_SPY_DFII10_CORR` | 风格因子 vs 实际利率 | 风格因子的利率敏感度 |
| `SPY_T10YIE_CORR` | 标普 vs 通胀预期 | 常与实际利率方向相反 |
| `SPY_DXY_CORR` | 标普 vs 美元 | 符号随周期翻转；转负对应海外营收压力 |
| `NFCI_HY_CORR` | NFCI vs HY OAS | 金融条件→信用利差 |
| `HY_VIX_CORR` | HY OAS vs VIX | 0.85→0.6 以下说明股票端还没定价信用风险 |
| `NFCI_VIX_CORR` | NFCI vs VIX | 金融条件→股票波动的末端 |

> 相关系列在 UI 单独显示当前值、60 期前值与差值，**不**做 Z 变换，避免把符号抹掉。

## 4. 预置与看什么

| 预置 | 线 | 重点 |
|---|---|---|
| 久期风格 | QQQ/SPY ln、DFII10、T10YIE | 风格因子与实际利率的相关是否由负转正 |
| 纳指×实际利率 | QQQ、DFII10、T10YIE、SPY | 纳指−标普敏感度差；差值收窄=久期溢价消失 |
| 半导体×纳指 | SMH/QQQ ln、SMH、QQQ | 分子（订单）还是分母（利率）驱动 |
| 实际利率拆分 | DFII10、T10YIE、SPY | 实际利率与通胀预期方向相反；看相关符号 |
| 金融条件传导 | NFCI、HY OAS、VIX | 拐点时间差；OAS 上行而 VIX 未跟=股票端未定价 |
| 盈利×利率 | DGS10、SPY | 前瞻 EPS 无免密稳定源，只画利率与标普，不伪造 EPS |
| 美元×标普 | DXY、SPY | 美元与美股相关转负=海外营收压力 |
| 流动性管道 | WALCL、RRP、WRESBAL、SPY | 周度/日度混频只做同轴 Z，不插值 |
| 信用-波动 | HY OAS、VIX | 信用先走、VIX 未跟的背离 |
| 曲线-长端 | 2s10s、10Y | 倒挂后重新陡峭化 |

## 5. 边界

- **前瞻 EPS 未接入**：FRED 没有现成序列，免费源不稳定；为避免用模拟值冒充，预置里只画利率与标普，并在 UI 明示。要接的话需要 FMP / Alpha Vantage / 付费一致预期源。
- **NFCI / WALCL / RRP / WRESBAL / HY OAS 仍依赖 FRED**：FRED 完全不可达时这些线显示「缺」，不会插值。
- **周度序列**：NFCI、WALCL、WRESBAL、WTREGEN 是周度；与日度 SPY 对齐后，60 期相关约等于 60 周，不是 60 个交易日。
- **SOX 用 SMH 代理**：纯 `^SOX` 在腾讯/东财链路取不到；SMH 有真实成交价，三路兜底都能通。
- **不双轴**：所有 Z 线共用一根轴；相关系数单独面板。

## 6. 性能

- 叠加页只加载当前选中 + 相关配对需要的序列，不预取全量。
- 原始/派生序列 5 分钟缓存；FRED 有 5 分钟缓存 + 熔断；Yahoo 由 `fetchYahooDaily` 统一 8s 超时。
- 全球地形与叠加页共用 Treasury/Yahoo 取数；跨资产不再等待 FRED（利率由财政部覆盖）。
- 冷启动优先读 localStorage（crossAsset / positioning / snapshot），先画后刷。
- 实测：清空缓存后首屏到 38/38 约 1~3 秒（网络与节点不同会有波动）；旧实现约 20 秒。
