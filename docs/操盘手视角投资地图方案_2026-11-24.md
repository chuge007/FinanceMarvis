# Marvis·投资地图 —— 操盘手视角的全面重构方案

> 版本：2026-11-24 ｜ 视角：**一线操盘手 + 产品经理** ｜ 性质：全新方案（未改动源码）
>
> 这份不是修补缺陷的清单，而是一次**角色重设**：假设我是一线操盘手，每天真的靠这个软件做决策，
> 我会怎么改、加什么功能、砍什么花架子，才能让它成为我的"投资作战地图"。
>
> 与前三份的定位不同：前三份分别修可用性、修图表准确性、修产品体验；本份是**升维**——把定位从"给新手的财务规划工具"抬到"给主动投资者的每日作战地图"，用多指标叠加与相关性分析把已有的真实数据真正用起来。

---

## 0. 一句话定位转变

- **现在**：给新手的"钱怎么分"计算器 + 一堆各自为战的仪表盘（用完即走）。
- **应该成为**：一个操盘手每天早上打开、30 秒读完"隔夜发生了什么、市场体制变没变、我的地图要不要动"的**作战地图**。
- **核心手段**：把已经拉到的真实宏观序列**归一化叠加**、算**相关性**、找**背离**——让"趋势"和"联动"一目了然，而不是拆成一堆孤立的分位数字。

一句话：**数据你已经有了，缺的是把它们叠加起来看的眼睛。**

---

## 1. 操盘手的一天：这个软件应该嵌入哪个动作

真正主动投资的人，工作流是固定的。软件的价值在于嵌入这些动作，而不是让用户"随便点点看"：

| 时点 | 操盘手在做的事 | 软件该提供什么（现状 vs 应有） |
|---|---|---|
| 开盘前 / 晨会 | 扫隔夜：美股、VIX、信用利差、美元、利率怎么动了？ | ❌ 现在是 8 个分散分位条 → ✅ **一页「作战简报」+ 叠加图** |
| 判断体制 | 现在 risk-on 还是 risk-off？该进攻还是防守？ | 🟡 rhythm 有 tone 但看不到"怎么来的" → ✅ **贡献分解 + 体制历史带** |
| 找背离 | 价格和信用/波动是不是背离？有没有假信号？ | ❌ 完全没有 → ✅ **领先-滞后背离扫描** |
| 看联动 | 股债相关性变了吗？美元和风险资产还反向吗？ | ❌ 完全没有 → ✅ **滚动相关性矩阵** |
| 选方向 | 钱在往哪流？哪些板块在走强、强得持续吗？ | 🟡 有演示轮动 → ✅ **真实板块轮动强度** |
| 执行 | 按体制调仓位、再平衡、设风险预算 | 🟡 有工具但不联动 → ✅ **体制→仓位联动建议** |
| 复盘 | 记录决策、回看质量（非盈亏） | 🟡 只记不归因 → ✅ **决策归因（把当日体制打标）** |

**结论**：这套动作软件覆盖了 60%，但都是碎的。重构的核心不是"加更多页"，而是**围绕"盘前决策"这一个高频动作，把碎的能力串成一条线**。

## 3. 核心：五张叠加 / 相关性分析图（本方案的心脏）

以下是操盘手真正会盯着看的五张图。每张都给出：**解决什么判断问题 / 怎么算 / 怎么看 / 界面长什么样**。
（效果示意见配套的"风险温度叠加图 + 相关性矩阵"可视化）

### 3.1 风险温度叠加图（Risk Temperature Overlay）★最优先

- **解决的问题**：8 个指标分散看，用户不知道"现在整体风险是真的在升，还是又一个假信号"。叠加后，**多指标同向 = 高可信；只有一条动 = 背离，别急**。
- **怎么算**：每条序列先归一化到可比尺度，再叠在同一时间轴上。
  - 归一化用 **Z-score**：`z = (x − 均值) / 标准差`（用滚动 250 日窗口的均值和标准差，避免用全样本造成未来函数）。
  - 月度序列（CPI/失业率）先对齐到日轴（前向填充），并**用虚线区分**，避免和日度指标混读。
- **怎么看**：
  - 多条风险指标（VIX↑、HY OAS↑、美元↑、期限利差↓）**同向恶化** → 防守信号可信度高；
  - 只有一条异动、其余背离 → 标注"背离·待确认"，不触发防守；
  - 领先指标（HY OAS、期限利差）先转、同步指标（VIX、情绪）后跟 → 提示"预警在前"。
- **界面**：一张多线叠加图（不同颜色 + **实线/虚线/点线** 区分，不只靠颜色）；顶部一条结论条："4 项中 3 项同向恶化 → 风险升温（置信中）"。
- **去双轴**：全部归一化到同一 Z 轴，**绝不用双 Y 轴**（双轴会制造虚假相关，前一份方案已列为禁忌）。

### 3.2 滚动相关性矩阵（Rolling Correlation Matrix）

- **解决的问题**：分散化的前提是"资产之间不同步"。当股债从负相关转正、美元与风险资产从反向转同向，**分散化失效、体制正在切换**——这是操盘手最需要提前看到的。
- **怎么算**：
  - 对每对指标，用滚动窗口（默认 60 日，可切 20/120）算 **Pearson 相关系数**；
  - 对非正态、含极端值的序列用 **Spearman 秩相关** 更稳健（可切换）；
  - 输出 6×6 或扩展后的矩阵，颜色编码：红=正相关，蓝=负相关，越深越强（配数值，不只靠颜色）。
- **怎么看**：对角线恒为 1；重点看非对角元**随时间的变化**——提供一个"相关性变化"视图（当期 vs 60 日前），突变格高亮。
- **界面**：热力矩阵 + 一个"相关性突变"提示条（如"美元-风险资产相关性 30 天内由 -0.3 转 +0.2，留意体制切换"）。

### 3.3 领先-滞后交叉相关（Lead-Lag Cross-Correlation）

- **解决的问题**：验证"领先指标真的领先吗、领先多久"。这是把 rhythm 里凭经验标注的"领先/同步/滞后"变成**可量化证据**。
- **怎么算**：对两条序列在不同滞后 k（如 −30…+30 日）上算相关系数，画**滞后-相关曲线**，峰值所在 k 就是历史领先/滞后天数。
- **怎么看**：HY OAS 与 SPX 的交叉相关峰值若在负滞后，说明信用利差历史上先于股市反应某 N 天——给"预警在前"提供数据背书。
- **界面**：小倍数图（每对一行滞后-相关曲线，标注峰值 lag）。进阶功能，放在"专业视图"里。

### 3.4 体制历史带（Regime Timeline）

- **解决的问题**：现在只有一个"当前 tone"（进攻/均衡/防守/观望），用户不知道"历史上处在类似位置时，后面发生了什么"。
- **怎么算**：复用 rhythm 的 `buildRegime` 合成分数，**回溯计算历史每日的 regime**，画成一条时间色带（绿=进攻…橙=防守…紫=观望）。
- **怎么看**：看当前色块在历史上的**位置分布**，以及"同类色块之后"的波动/回撤统计（**只做描述，不做预测**）。
- **界面**：一条横向色带 + 当前指针 + "历史上'防守'状态平均持续 X 天、其后 20 日波动区间为…"的描述性统计。

### 3.5 板块-大盘相关性 + 轮动强度（真实数据）

- **解决的问题**：板块轮动现在整页是演示数据，没有实际用处。真问题不是"哪个板块热"，而是"这个板块的强势**是否持续、是否与大盘脱钩**"。
- **怎么算**：用东财板块指数日线，算每个板块相对大盘的**超额收益斜率**（轮动强度）与**相关性**（是否走出独立行情）；用相对强弱线（RS Line）判断趋势。
- **怎么看**：强者恒强看 RS 线是否新高；相关性下降=开始走独立逻辑（可能是新主线）。
- **界面**：板块 RS 排行 + 每板块一条相对强弱迷你线；演示数据要么接真实、要么整块标注"教学示例"。

作为操盘手，我会非常果断地做减法——**留着的每个功能都要能回答"它帮我做了什么决策"**。

| 处置 | 功能 | 理由 |
|---|---|---|
| 🔴 砍 | 模拟交易演示页 | 纯练习、无真实价值，分散注意力；需要练习不如用真实小额 |
| 🔴 砍/降级 | 板块轮动演示数据页 | 演示数据 + 给"加仓/减仓"建议，既不真实又踩合规红线；要么接真实数据，要么撤 |

## 5. 让功能"有实际用处"：从"看数据"到"做决策"的三处闭环

数据看得再多，不落到动作就是娱乐。这三处是让功能真正有用的关键：

### 5.1 体制 → 仓位联动（不给买卖点，只给"该多重"）
- 现有 `rhythm.ts` 已经产出 `riskBudget` 文本，`discipline` 有仓位计算器，但两者不通。
- **改法**：把当前 regime 的 tone 直接喂进仓位计算器——防守态自动把"单笔风险预算"默认值从 2% 降到 1%，并显示"因为当前是防守态"。用户仍可手动改，但默认值随体制走。
- **价值**：这是"数据→决策"最短的一条路，且完全合规（调的是仓位上限，不是买卖信号）。

### 5.2 决策归因：复盘时自动记录"当时什么体制"
- 现在复盘日志要手动填"当时市场状态"（`Journal.tsx`），用户懒得填。
- **改法**：新建复盘条目时**自动带上当日 regime tone + 关键指标分位快照**，事后能看"我在防守态下的决策胜率 vs 进攻态"。
- **价值**：把"记录"变成"可分析"，这是产品差异化（复盘决策质量而非盈亏）的真正落地。

### 5.3 背离预警：把"该看一眼"变成"主动提醒"
- 当领先指标（HY OAS/期限利差）分位显著变动而同步指标（VIX/情绪）未跟随时，生成一条"背离提示"，进入每日简报和告警。
- **价值**：这是操盘手最看重的"转折前兆"，把被动看盘变成主动提示。

## 6. 新首页：每日作战简报（Daily Battle Brief）

把默认首页从"填表配置"改为"盘前一页看完"（老用户），新用户仍先走配置。结构：

```
┌─────────────────────────────────────────────┐
│ 今日作战简报 · 2026-11-24 盘前               │
│                                             │
│ 【一句话】市场体制：防守 · 你的地图建议：维持  │
│ 【隔夜变化】VIX +X% / HY OAS +Xbp / 美元 +X%  │
│ 【背离提醒】信用利差走阔但 VIX 未跟 → 留意     │
│ 【叠加图】  (3.1 风险温度叠加缩略图)          │
│ 【相关性】  股债相关性本周转正 → 分散化减弱    │
│ 【你的持仓】距再平衡阈值还差 X%               │
│                                             │
│ [看完整分析]  [记录今日决策]                  │
└─────────────────────────────────────────────┘
```

- 全部数字挂来源徽章（真实/模型/不可用）；
- 断网时整页显示"数据不可用"，绝不回填写死值；
- 30 秒能读完，想深入再点进各分析图。

## 9. 边界（操盘手也要守的红线）

- **不给买卖信号/目标价**：叠加、相关、背离都只描述"环境与联动"，最终"买什么"留给人。
- **不承诺预测**：体制历史带只做"历史上类似位置发生了什么"的描述，不做"接下来会怎样"的承诺。
- **不用双轴制造虚假相关**：归一化统一 Z 轴，相关性用矩阵而非双线误导。
- **不编造数据**：取不到就显示"不可用"，叠加图缺一条就明说缺哪条、置信度下降。
