## 0. 本方案与旧方案的关系

`docs\金融数据融合方案_2026-11-27.md` 的三条结论在本方案中被**明确覆盖**：

|---|---|---|
| D1「融合 ≠ 全部接入，只登记不装进程序」 | **融合 = 源码全量收藏 + 功能全量可见 + 数据尽量可用** | 用户要求「所有功能和数据都要显示」 |

## 2. 全量功能盘点：自动抽取，不靠人工写清单

### 2.1 生成器

新增 `scripts\gen-project-capabilities.mjs`，扫描 `Github\<dir>`：

- Python：解析 `*.py` 的顶层 `def` / `class` 及 `__all__`，取公开 API（`_` 开头除外），重点抓 `__init__.py`、主模块名与 `README.md` 的功能段落。
- JS/TS：解析 `export` / `module.exports`（ccxt、OpenBB 前端）。
- CLI：解析 `pyproject.toml` / `setup.py` 的 `entry_points`、README 的 `freqtrade xxx` 命令。
- 每个能力输出一条记录，写入 `src\core\data\projectCapabilities.generated.ts`。

### 2.2 能力记录结构

```ts
type Capability = {
  id: string;              // 'akshare:stock_zh_a_hist'
  project: string;         // 'akshare'
  name: string;            // 中文功能名
  category: '行情'|'K线'|'财务'|'资金流'|'板块'|'基金'|'债券'|'期货'|'外汇'|'宏观'|'另类'|'情绪'|'研报'|'回测'|'交易'|'绩效'|'工具';
  markets: ('cn'|'hk'|'us'|'global'|'crypto')[];
  dataKind: 'live'|'eod'|'snapshot'|'compute'|'tool';
  stability: 'S1'|'S2'|'S3'|'S4'|'S5'|'S6'|'TOOL';
  status: 'live'|'backup'|'key-required'|'python-required'|'catalog-only'|'external-only';
  primaryFor: string[];    // 该项数据在 Marvis 中的主源数据集 id
  fallbackFor: string[];   // 备源数据集 id
  requires: ('key'|'python311'|'local-server'|'proxy')[];
  ui: string;              // 在哪个页面/标签可见
  sourcePath: string;      // Github 下的相对路径，便于溯源
};
```

> `status` 是**事实标签**，不是愿景：`catalog-only` 就写「仅目录」，不许伪装成已接入；`python-required` 要写清需要哪个库。

### 2.3 三项保证

1. **不漏**：26 个项目 100% 出现在能力清单；每个项目至少 1 条能力。
2. **不假**：没有取到数就显示「缺」，并点名缺哪条线；演示数据继续带 `SourceBadge` 标注。
3. **可溯源**：每条能力点开能看到来源仓库、文件路径、上游文档链接。

## 4. 融合架构：五层，一层一职责

| 层 | 名称 | 职责 | 落点 |
|---|---|---|---|
| **L0** | 源码资产层 | 26 个项目的源码、版本、许可证留在 `Github\`，只读；提供能力抽取与溯源 | `D:\FinanceMarvis\Github\` |
| **L1** | 直连层 | 免 Key 免 Python：29 条上游注册表 + adapters，TTL 缓存、代理回退、历史落库 | `server\upstream\registry.mjs`、`server\adapters\*.mjs` |
| **L2** | Key 通道层 | Tushare / FMP / Alpha Vantage / Twelve Data / DataBull / Nasdaq Data Link；无 Key 自动摘除链路并提示 | `server\adapters\optional.mjs`、`server\config.mjs` |
| **L3** | Python 能力侧车 | 独立进程、方法白名单、按库导入、失败冷却；扩展 `data_main.py` 覆盖 AkShare/baostock/efinance/ADATA/yfinance/edgar/ccxt/OpenBB/pandas-datareader 的展示型能力 | `sidecar\data_main.py`、`server\local\dataSidecar.mjs` |
| **L4** | 本地计算层 | 绩效指标、回测任务（Backtrader/vectorbt/RQAlpha 作为可选引擎）、结果落 SQLite；**不接实盘下单** | `core\domain\factors.mjs`、`sidecar\strategy_main.py`（可选） |
| **L5** | 产品视图层 | 双视角 UI：操盘手「决策任务视图」+ 产品经理「能力资产视图」 | `src\App.tsx`、`src\modules\v4\ArchivePage.tsx`、新增 `src\modules\catalog\UniversePage.tsx`、`src\modules\strategy\StrategyPage.tsx` |

调用链：

```
Github 源码 ──(gen-project-capabilities)──> 能力清单 ──> 全景页/档案页（L5）
                                                  │
用户点击某项数据 ──> L5 ──> /api/v1/* ──> L1 直连 ──> 上游（最稳定主源）
                                  ├──> L2 Key 通道（有 Key 才注册）
                                  ├──> L3 Python 侧车（有 Python 3.11 + 库才可用）
                                  └──> L4 本地计算（回测/绩效，结果落库）
失败 ──> 备源 ──> 「缺」（点名原因），不插模拟值
```

## 5. 操盘手视角：按「决策任务」分配功能与数据

> 操盘手不关心「这是哪个库」，只关心「我现在要做什么判断、看哪条线、数据可不可信」。

### 5.1 一日作战流

| 时段 | 任务 | 看的页面 | 关键数据（主源） | 交互 |
|---|---|---|---|---|
| 盘前 | 全球风险偏好定调 | 今日 / 地形 | 美债 10Y、DXY、VIX、原油、美元流动性（FRED / 财政部 / NY Fed） | 一屏看 8 条核心线，异常高亮 |
| 盘前 | 今日事件与财报 | 日历 | FOMC、WSCN 日历、EDGAR 已提交文件 | 按北京时间排序，标注「预约」vs「已发生」 |
| 盘中 | 指数与板块强弱 | 雷达 / 地形 | 腾讯指数、31 行业资金流 | 热力图 + 主力净流入（统一亿元） |
| 盘中 | 个股异动与龙虎榜 | 盘口 / 决策 | Tushare 两融/龙虎榜，AkShare 备源 | 席位口径分列，不合并统计 |
| 盘后 | 持仓风险归因 | 组合 / 决策 | 自建 factors（波动、回撤、分位） | 每条指标显示公式与数据主源 |
| 盘后 | 复盘与策略验证 | 策略（新增） | Backtrader / vectorbt / RQAlpha 本地回测结果 | 可选引擎，结果落库，不荐股 |
| 随时 | 数据可信度检查 | 全景 / 数据 | 健康条、主源标签、降级记录 | 点「缺」看原因，一键跳到配置 |

### 5.2 操盘手页面规则

1. **每条线都带来源徽标**：官方 / Key / 交易所 / 爬虫 / 派生 / 演示，颜色与 `SourceBadge` 语义一致。
2. **同屏不混口径**：A股财务（Tushare）与美股财务（EDGAR）分栏；主源与备源分栏；实盘与演示分栏。
3. **异常优先**：数据缺失、源降级、超过 TTL 未更新时，在页面顶部显示条幅，点名缺哪条线。
4. **可下钻**：从「板块异动」点进成分股 → 个股 K 线 → 财务 → 公告，全程保持主源一致。
5. **策略台合规**：只展示回测结果与风险指标，不输出目标价、买卖点、评级；不提供下单入口。

## 8. Python 运行时策略（当前环境硬约束）

**实测**：本机只有 Python 3.8.3（`py -0` 仅列出 3.8）；而 `sidecar\requirements-data.txt` 要求 ≥3.11（AkShare 1.18+、edgartools 2+、ccxt 4+）。

| 方案 | 做法 | 取舍 |
|---|---|---|
| A（推荐） | 下载 Python 3.12 嵌入式版到 `D:\FinanceMarvis\runtime\python312\`，`MARVIS_PYTHON` 指向它；`pip install -r sidecar\requirements-data.txt` 到该环境 | 不动系统 Python；exe 仍不内嵌解释器；用户首次使用时一次性准备 |
| B | 用户自行安装 Python 3.11+，`MARVIS_PYTHON` 指向系统解释器 | 零下载，但要求用户操作 |
| C（过渡） | 不装库，L3 能力全部显示 `python-required` / 「缺」 | 零风险，但加密/EDGAR/基金等数据不可用 |

**统一出口**：`server\local\dataSidecar.mjs` 已支持 `MARVIS_PYTHON` 覆盖；全景页缺口看板给出对应安装命令，用户按 A 或 B 任选。

## 10. 风险与边界

| 风险 | 处置 |
|---|---|
| 源码体积大（OpenBB/ccxt/vnpy 等） | 浅克隆、只读参考；不进前端 bundle、不进 exe |
| 许可证差异 | 能力清单记录许可证；仅抽取 API 名称与文档链接，不复制实现代码进产品 |
| Python 3.8 不满足依赖 | 按第 8 节选择方案 A/B；未满足时全部 L3 能力显示「缺」 |
| 爬虫源无 SLA / 源站改版 | 只做展示型补充与备源；TTL + 落库 + 失败冷却；不做财务主源 |
| 概念膨胀 | 26 项目全部收进 `全景` 与 `策略` 两个入口，不散落到 11 个旧页面 |
| 主源单点 | 主源未就绪即降级到备源并明示；无备源显示「缺」，不补假值 |
| 合规 | 回测只做本地研究；不接 CTP/交易所下单；不荐股、不给目标价 |
| 视觉可读性 | 新增文字 ≥12px（0.75rem）；1920×1080 实测无横向溢出；不沿用旧 9~11px 固定字号 |
