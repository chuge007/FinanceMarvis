5. 系统将在价格达到时通知

#### 📈 技术分析
1. 点击 "📈 技术分析"
2. 输入股票代码 `600519`
3. 查看 MA/MACD/RSI/KDJ/BOLL 指标
4. 阅读综合信号提示

#### 🔄 板块轮动
1. 点击 "🔄 板块轮动"

2. 创建账户（初始资金 10万）
3. 买入：代码 `600519`，数量 `100`，价格 `1850`
4. 查看持仓和盈亏
5. 卖出测试

## 🔧 配置说明

### IndexedDB 配置
数据库自动初始化，默认配置：
- 数据库名: `StrategyLabDB`
- 版本: `1`
- 存储表: `quotes`, `positions`, `trades`, `alerts`

### 告警通知配置
首次使用需要授权桌面通知：
```javascript
// 浏览器会自动弹出授权请求
// 或手动调用：
import { requestNotificationPermission } from '@/stores/useAlertStore';
requestNotificationPermission();
```

## ⚠️ 注意事项

1. **浏览器兼容性**
   - IndexedDB: Chrome/Edge/Firefox/Safari 全支持
   - 桌面通知: 需要用户授权

2. **数据安全**
   - 所有数据存储在本地浏览器
   - 清除浏览器数据会丢失记录
   - 建议定期导出重要数据（功能待开发）

3. **性能优化**
   - IndexedDB 适合存储大量历史数据
   - 建议定期清理过期数据（已内置功能）
   - 模拟交易账户建议不超过 5 个
