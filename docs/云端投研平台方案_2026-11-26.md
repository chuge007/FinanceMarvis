# 云端投研平台与全量数据接入方案（2026-11-26）

> 目标：从单机投研工作台升级为「云端多用户平台 + 本地行情网关」的混合产品。
> 云端负责长周期数据、异步研究、组合风控与协作；本机负责必须登录券商账户的实时行情与交易。

## 1. 五个 Skill 的源码勘察结论

| Skill | 实际取数链路 | 能拿到什么 | 硬限制 |
|---|---|---|---|
| **market-fin-data** | `market_data.py` 14 个子命令（quote/wb/treasury/rrp/fred/bis/hithink/cn/us/eia/cot/stablecoins/jgb/carry/ratios）+ hithink/westock CLI | 中美宏观、官方曲线、中国官网、SEC EDGAR、EIA、CFTC、稳定币、套息仪表盘、商品比价 | 402/429 立即降级；H 源约 4-5 次/20s |
| **富途行情与交易** | 58 个 Python 脚本经 OpenD `127.0.0.1:11111`；`OpenQuoteContext` + `OpenSecTradeContext` | 快照/K线/逐笔/买卖盘/经纪队列/分时/资金流四级/条件选股/期权链/窝轮/IPO/板块 + 14 个交易接口（账户/持仓/订单/成交/费用/保证金） | 需 Python + futu-api ≥10.4.6408 + OpenD 登录；港股实时需 LV1+；快照≤400、history_kline≤1000、订阅 1 分钟内不可退订；K 线额度按账户等级 |
| **万象 omni-finance** | NeoData HTTP、WeStock CLI、朝阳永续 MCP、WSCN 公开日历、盈米 MCP | A/港/美股全品类；一致预期、批量选股、可转债、基金诊断；财经日历 actual/forecast/previous/importance；九模块投研工作台 | 需 key/CLI/浏览器；WSCN 仅未来 1-2 月；朝阳按积分 |
| **万得 Alice** | A2A JSON-RPC（`message/send`、`tasks/get`、`tasks/resubscribe`）+ Bearer Key + 附件下载 | 信用六维与 PD、SAA/TAA、研报公告财报语料、Excel/PPT/PDF 建模 | 2-15 分钟/次；并发上限；10 分钟内重复 prompt 拒绝；**本地无 Wind 数据库直连**，返回自然语言+附件 |
| **airoom** | Playwright 爬虫抓官网 CSV（三件套） | 20+ 市场日度环境分数（优秀/良好/差/恶劣）、极端涨跌家数、达标标的数 | 实测官网页面可达但**无 CSV 直链**；分数由平台算好，本地无评分代码 |

### 落地取舍

- airoom 无 CSV 直链 → 改为**可选文件导入**，不伪造网络抓取；跨市场雷达用本地真实序列自算分数，第三方分数分列展示。
- 富途 OpenD 在用户本机 → 必须走 Python 侧车，云端无法直连；断网时本机仍可用。
- Wind 无结构化输出 → 在 prompt 末尾追加 JSON 约定，实现三层解析（json 块 → Markdown 表格 → unstructured），并标 confidence。

## 2. 架构：一份领域内核，两种运行形态

```
本机                                      云端
┌────────────────────────┐          ┌──────────────────────────┐
│ React 本地界面          │          │ React Web（多用户）        │
│ Node 网关 server/       │          │ API 网关 + JWT/RBAC        │
│ Python sidecar          │          │ core/domain（同一份）       │
│ OpenD 127.0.0.1:11111   │          │ Redis 队列 / PostgreSQL     │
└───────────┬────────────┘          │ workers / 对象存储          │
            └── 实时快照上报 ────────▶└──────────────────────────┘
```

- `core/domain/*.mjs`：**唯一一份**数据契约、因子、体制、归因、风险规则；前端通过 `allowJs` 直接 import，后端原生 import，杜绝两端口径分叉。
- `server/cloud/*`：可选启用；未安装 pg / bullmq 时自动降级 SQLite + 内存队列，本地 exe 行为不变。
- `sidecar/*`：Python 3.8+ 兼容，stdio JSON-RPC，方法白名单，侧车不可用不影响其它功能。
- `/api/v1` 本地接口保持兼容；`/api/v2` 在 v1 之上加认证与租户隔离。

### 风控规则的修订（risk-manager 评审后）

- VaR 样本从 30 提高到 100，CVaR 250；不足返回 `unverified`，不再静默通过。
- Sharpe/Sortino 年化因子参数化，不再硬编码 252。
- Brinson 权重统一为小数并校验合计为 1；先算原值再统一舍入。
- 漂移分档：大类 2/4pp，单券与行业 1.5/3pp 并叠加相对 20%/50%。
- 新增 HHI/有效持仓数、相关性拥挤、流动性变现（ADV 折价）规则。

## 6. 运维

| 项 | 说明 |
|---|---|
| 本地模式 | 双击 `Marvis.exe`，数据 `%APPDATA%/Marvis` |
| 云模式 | `MARVIS_CLOUD=1 JWT_SECRET=... MARVIS_MASTER_KEY=... node server/index.mjs` |
| 初始化账号 | `node scripts/cloud-admin.mjs create-admin admin '<密码>'` |
| 数据迁移 | `node scripts/cloud-migrate-data.mjs --to=<云数据目录>` |
| 探源 | `npm run probe`（序列 88/88，快照 5/6，CFTC 需 token） |
| 回填 | `node scripts/backfill-cli.mjs` |
| Wind | 设置 `WIND_API_KEY` 或 `~/.wind-aifinmarket/config.env` |
| 富途 | 安装 futu-api≥10.4.6408 + OpenD 登录；exe 已内嵌侧车脚本 |
| airoom | 把 `APIshujubaocun.csv` 放到数据目录 `airoom/` |
| 真实交易 | 需 `MARVIS_ALLOW_REAL_TRADING=1` 且由上层二次确认，默认模拟盘 |

## 7. 未完成与边界

1. 朝阳永续 / NeoData / 盈米只做了路由与契约，未实现调用（需 MCP/key 与积分）。
2. 选股工厂前端未上线（后端 `stockFilter` RPC 已就绪）。
3. 云端只实现单实例可运行形态（SQLite + 内存队列）；生产多实例需装 `pg` + `bullmq` 并设 `DATABASE_URL` / `REDIS_URL`。
4. 实时 tick 的 WebSocket 上报只留了接口，未做持久化与多端订阅。
5. Wind xlsx 附件解析未实现（第三层回退目前落到 unstructured）。
6. 平台定位为数据与判据工具，不提供投资建议、不代客决策（沿用万象铁律）。
