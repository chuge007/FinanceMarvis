# 全球宏观 / 微观数据源与「市场地形」方案

> 日期：2026-11-25 ｜ 视角：一线交易员 ｜ 性质：实现说明 + 长期查阅手册
>
> 一句话：**宏观决定钱的价格，微观决定钱有没有真的在买；同向才可信，背离就只留意。**

---

## 1. 为什么交易员必须高频看宏观与微观

### 1.1 宏观：估值的分母

任何资产的价格都可以拆成「未来现金流 ÷ 折现率」。宏观数据不直接告诉你买什么，但它决定折现率：

- **政策利率与美债收益率**：10Y 是全球资产定价的锚，2Y 是对美联储路径的下注；
- **实际利率（TIPS）**：真正压成长股估值的是实际利率，不是名义利率；
- **美元**：全球美元流动性潮汐，美元走强时新兴市场与风险资产同时受压；
- **信用利差（HY OAS）**：企业融资成本的实时报价，通常先于股市反应；
- **通胀预期**：决定降息空间，也决定商品与价值/成长的相对强弱。

宏观的用法不是预测下周涨跌，而是回答：**现在这个环境，值不值得承担风险？**

### 1.2 微观：现金流与持续性

同一个「风险偏好回升」的宏观叙事，可能对应完全不同的微观事实：

- 股指期货在涨，但 ETF 在净流出 → 上涨靠空头回补，不牢；
- 指数在涨，但上涨家数在减少 → 宽度背离，行情集中在少数权重；
- 信用利差在走阔，但 VIX 没动 → 信用先走、波动未跟，是常见预警；
- 期权 Put/Call 极低 → 人群已经站到一边，任何坏消息都会被放大。

微观回答的是：**钱有没有真的在买、买的是谁、买到什么程度了？**

### 1.3 为什么要「经常看」

- 宏观数据是**低频、滞后**的（CPI、非农、失业率），但市场对它的**预期**是高频的；
- 微观数据是**高频、领先**的（期指、信用、波动、期权、资金流），但噪声大；
- 两者的组合才构成「体制」：环境（宏观）+ 位置（微观）+ 拥挤度（仓位）。
- 每天看，是为了在体制切换的**早期**降低换手，而不是等新闻确认后追涨杀跌。

### 1.4 看数据的四档节奏

| 节奏 | 时间成本 | 看什么 | 目的 |
|---|---|---|---|
| 每日盘前 | 10 分钟 | 期指、美债、DXY、VIX、油价、隔夜新闻 | 判断今天是否需要调整风险预算 |
| 每周 | 20 分钟 | CFTC COT、ICI 货基、ETF 周度净流入、AAII/NAAIM | 判断仓位拥挤度与资金方向 |
| 每月 | 30 分钟 | CPI/非农/PCE/ISM、FINRA 保证金、IIF/央行数据 | 确认宏观体制是否变化 |
| 每季 | 1 小时 | 13F、财报季、SEP 点阵图、ACM 期限溢价 | 检查结构性假设是否仍成立 |

**原则：高频数据用来「检查」，低频数据用来「确认」；不要用低频数据做择时。**

## 3. 地图怎么用这些数据画出「完整的市场」

### 3.1 地图的四个层次

```
环境（宏观，钱贵不贵）
  → 地形（跨资产，风险偏好与流动性现在在哪）
    → 结构（微观，钱往哪走、谁在走强）
      → 我方（我的仓位与目标带的偏离）
```

原有「传导链 + 三层图」保持不变；新增「全球地形」补上**横截面**：
链回答「怎么传过来」，地形回答「现在世界长什么样」。

### 3.2 全球地形的六组数据

| 组 | 代表数据 | 回答的问题 |
|---|---|---|
| 股指期货 | ES/NQ/YM/RTY、DAX/FTSE/日经/恒指/上证 | 隔夜谁在领涨、谁在拖后腿 |
| 美债与利率 | 2/5/10/30Y、2s10s、3m10y、实际利率、通胀预期 | 钱的价格与曲线形状 |
| 信用与风险 | HY OAS、VIX、HYG-LQD、SKEW | 市场愿意为风险付多少钱 |
| 美元与商品 | DXY、EUR/USD、USD/JPY、USD/CNH、WTI、黄金、铜、铜金比 | 全球美元流动性与实物需求 |
| 仓位与资金 | CBOE P/C、VIX 期限比、SPY/QQQ 成交活跃度、FG | 人群站在哪一边、成交是否放大 |
| 加密温度计 | BTC、ETH | 7×24 的流动性代理 |

每个格子显示：名称、最新值、日变动、近一年分位条、来源点。
点击展开：近 90 日迷你线、Z 值、20 日 Z 变化、为什么看、常见误读、外部核对链接。

### 3.3 两个合成分：风险偏好与流动性

```
风险偏好 = clamp(50 + 10 × mean(polarity × z), 0, 100)
流动性   = clamp(50 + 10 × mean(polarity × z), 0, 100)
```

- `z` 是各自 250 日滚动 Z（只用截至当天窗口，避免未来函数）；
- `polarity = +1`：越高越 risk-on（股指、铜、铜金比、BTC）；
- `polarity = -1`：越高越 risk-off / 钱越紧（VIX、HY OAS、DXY、实际利率、收益率）；
- `polarity = 0`：方向不明，只展示不参与打分（WTI、Put/Call、成交量比、FG）；
- 缺失按剩余样本平均，并显示「样本 x%」；覆盖不足时结论自动降级。

### 3.4 象限罗盘

- X 轴：流动性（右松左紧）
- Y 轴：风险偏好（上强下弱）
- 四象限：金发姑娘 / 再通胀 / 避险 / 紧缩
- 显示今天位置 + 近 60 个交易日轨迹，轨迹逐日重算、日期严格匹配、缺数据不连线

### 3.5 一句话结论

由规则生成，例如：

```
钱在变紧（DXY +1.2σ、实际利率 +0.6σ）
→ 风险偏好偏弱（HY OAS +1.1σ、VIX +0.4σ）
→ 总 Put/Call 0.92（常态）
```

这行字是整张地形的「主线」，不是每格各说各话。

## 4. 口径、边界与降级

### 4.1 口径

- 价格类用日线收盘，期货为连续合约（有换月跳空）；
- 利率单位为 %，日变动显示 bp；曲线显示 pt；
- 分位是近一年样本内的相对位置，不是概率；
- 成交量比 = 当日量 ÷ 前 20 日均量，**只表示关注度，不是净流入**；
- HYG-LQD = 20 日收益差（百分点）；铜金比 = 铜价 ÷ 金价；VIX 期限比 = VIX ÷ VIX3M。

### 4.2 边界

- 不预测涨跌，不给买卖点或目标价；
- 不把相关性当因果；
- 不用成交量、价格、份额估算 ETF 净流入；
- 不用随机数、写死值或示例值填充主路径；
- CBOE Put/Call 只有当日值、没有历史，不参与分位与合成分。

### 4.3 降级

- 单组失败：该组显示「缺」，其他组照常；
- Yahoo 先 SPY 探针，再按 18 只/批走 spark；spark 缺的、以及 SPY/QQQ 成交量用单只 chart 补；整体不可达则跳过剩余请求；
- Yahoo 不可达时，恒生/上证用腾讯现货指数兜底（来源点橙色，标注「腾讯现货兜底」），期指/汇率/商品保持「缺」；
- 东财不可达时，A 股板块自动切换腾讯行业榜（含 5/20/60 日与主力净流入），再退新浪板块（仅当日价格）；
- 全部失败：整块显示「上游不可用，今日不给判断」；
- 快照/期权晚到：跨资产层会用原始缓存重新合成，不重复请求。

## 7. 本机网络与代理（2026-11-25 补充）

### 7.1 实测结论

| 现象 | 实测 | 原因 / 处置 |
|---|---|---|
| Yahoo 直连 403 | `curl` 直连 403；`curl --proxy http://127.0.0.1:7897` 200 | 地区限制；Node/Vite 不自动使用 Windows 系统代理。Vite 已给 `/yahoo` 挂探测到的代理 |
| 东财不可达 | `push2` / `push2his` 直连与经 7897 均连接重置 | 网络层阻断，加 header 无效；换腾讯行业榜 / 新浪板块 |
| FRED 偶发超时 | 直连有时 200、有时超时；经 7897 返回 000 | 不代理 FRED；先 Convex 镜像，再官方 CSV，利率腿最后由财政部曲线兜底 |
| 财政部曲线 | 200，2026 全年 CSV 18KB | `/treasury` 转发；补齐 2Y/3M/5Y/10Y/30Y，其余利率指标仍显示「缺」 |
| 腾讯行业榜 | 200，31 个行业，含 `zdf_d5/d20/d60`、`zljlr` | 东财第一替代源；`/tencent-rank` 转发 |
| 新浪板块 | 200，GBK 页面 | 第二兜底；`/sina-sector` 转发 + `TextDecoder('gbk')` |

### 7.2 代理探测顺序

`MARVIS_PROXY` → `HTTPS_PROXY` / `ALL_PROXY` → 本机 `7897 / 7890 / 10809 / 1080` → 直连。

- 走代理：Yahoo（`/yahoo`、`/yahoo-alt`）、CBOE（`/cboe`）、Convex（`/convex`）。
- 直连：FRED（`/fred`）、美国财政部（`/treasury`）、东财（`/eastmoney-*`）、腾讯（`/tencent-rank`）、新浪（`/sina-sector`）。
- 代理失败时，GET 请求回退直连一次；`/proxy-status` 返回实际使用的代理，数据健康条展开可见。

### 7.3 腾讯行业榜口径

- `zdf` / `zdf_d5` / `zdf_d20` / `zdf_d60`：当日 / 5 / 20 / 60 日涨跌幅（%）；
- `zljlr`：主力净流入，单位万元，程序 `/10000` 转亿元；
- `turnover` / `volume`：成交额 / 成交量，单位随接口，当前不用于打分；
- 只有 31 个行业，不含概念板块；板块涨跌数不是股票涨跌家数，UI 标注「板块口径」。
