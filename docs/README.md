## ❓ 常见问题

**Q: 为什么要从WebSocket开始？**
A: 因为实时性是所有后续功能的基础。30秒延迟对专业交易完全不可用。

**Q: 是否必须做完所有3个阶段？**
A: 不必须。Phase 1 (数据+持仓+预警) 已足以产生核心价值。Phase 2/3可按市场反馈调整。

**Q: 成本太高？**
A: 可以根据团队能力调整时间表。如果是兼职或小团队，可延长至18-24个月。

**Q: 如何处理数据源API变更风险？**
A: 多数据源冗余 + 抽象适配层。每个数据类型至少维护2个数据源。

**Q: 是否要做实盘交易对接？**
A: 建议先完成Phase 1/2充分验证，再考虑实盘。实盘有额外的安全和合规成本。
